# MemoryLane 抖音演示稿

> 视频时长：90-120 秒 | 语速：偏快但不赶 | 语气：朋友聊天感

---

## 第一段：钩子（0-8s）

**画面**：黑底白字弹出 "你有没有忘了和谁的约定？"

**口播**：
> 你有没有这种时候——微信里跟人约了事、聊了天，过了两周全忘了。我写了个工具，把你的聊天记录丢进去，AI 帮你全记住。

**画面**：切到 MemoryLane 首页

---

## 第二段：导入（8-25s）

**画面**：鼠标移到粘贴框，粘贴一段微信聊天记录（提前备好 test-conversations.txt 的内容）

**口播**：
> 从微信、QQ、抖音、短信……任何地方复制的聊天记录，直接粘贴进来，点解析。不用登录、不用扫码、不用破解数据库。

**画面**：点"解析"按钮，切到联系人页面，展示自动识别出的联系人

**口播**：
> 一秒识别出有几个说话人、什么平台、谁是谁。

---

## 第三段：记忆提取（25-50s）

**画面**：切到"记忆库"页面，展示 AI 自动生成的记忆卡片（提前确保有数据）

**口播**：
> 然后 AI 会在后台自动分析这段对话——他说过什么个人信息、有什么偏好、你们约过什么事、他是什么性格……全部提炼成结构化记忆。

**画面**：滚动记忆列表，指针停在一条"约定"类记忆上

**口播**：
> 比如这句"明天晚上找对方玩"，AI 自动识别出这是一个约定，然后解析出具体时间，提前半小时提醒你。

**画面**：切到"约定提醒"页面

**口播**：
> 到时间了浏览器弹通知，再也不怕鸽人。

---

## 第四段：军师模式（50-80s）⭐ 核心亮点

**画面**：切到"军师模式"页面，展示聊天模拟界面

**口播**：
> 最好玩的是这个——军师模式。

**画面**：对方发来一条消息（提前准备好 demo 对话），AI 给出 2-3 条回复建议

**口播**：
> 你朋友发来一句话，AI 基于你们之前的聊天记录，给你生成回复建议。不是那种"哈哈哈哈"的敷衍回复，是真的根据你俩的聊天风格来的。

**画面**：点一下风格选择器，切换到"幽默" → AI 给出新建议 → 再切"傲娇"

**口播**：
> 而且能切换风格——默认、幽默、可爱、温柔、高冷、傲娇……六种人设随便换。点一下就用。

---

## 第五段：搜索 + 收尾（80-100s）

**画面**：切回首页，在搜索框输入"发烧"

**口播**：
> 还有一个特好用的——全文搜索。搜"发烧"，能命中"lim 发烧刚好"这种不完整的词。中文分词专门优化过。

**画面**：展示搜索结果

**口播**：
> 再也不用翻半年前的聊天记录翻到手酸了。

---

## 第六段：C2A（100-110s）

**画面**：回到首页全景，右下角叠一个 GitHub 链接

**口播**：
> 这个项目叫 MemoryLane，完全开源，AGPL-3.0 协议。安装只需要装一个 Docker Desktop，然后一行命令就跑起来了。GitHub 链接在评论区，有完整的安装教程，每一步都写了。

**画面**：显示 GitHub 链接大字：github.com/denglizibinghua/MemoryLane

**口播**：
> 朋友多的、记性差的、想学 Spring Boot + AI 项目的，都可以看看。点个关注，下期见。

---

## 素材准备清单

| 素材 | 内容 | 时间点 |
|------|------|--------|
| 聊天记录 | 2-3 段包含约定的对话（提前导入，让记忆生成好） | 录制前 |
| 军师 demo 消息 | 1-2 条对方发来的消息，用于展示回复建议 | 录制前 |
| 搜索词 | "发烧"（命中已有记忆） | 录制前 |
| 首页截图 | 干净的首页，用于开头和结尾 | 随时 |

## 录制建议

- 用 OBS 录屏，不需要露脸
- 浏览器开无痕模式，隐藏书签栏
- 鼠标移动慢一点，给观众反应时间
- 可以在关键操作上画红圈标注
- BGM：轻电子 / lofi，音量低于人声
- 字幕：剪映自动识别 + 手动校对
